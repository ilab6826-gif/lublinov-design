# Lublinov Portfolio V2

Independent static portfolio: semantic HTML, CSS, and a small JavaScript file for the mobile menu. No package manager, framework, build step, or runtime dependency is required.

## Preview

From this folder, run:

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

Open <http://127.0.0.1:8768/>. Any free local port can be used.

## Pages

- `index.html` — homepage
- `work/project.html` — real PROJECT case
- `work/lumen.html` — concept
- `work/noir-atelier.html` — concept
- `work/mv-vape-shop.html` — real logo-design case

## Asset provenance and limits

Existing project imagery and video were copied unchanged from the prior portfolio into `assets/`. The LB logo SVG files and Manrope font were copied unchanged from the existing Lublinov identity exploration. The font license is in `fonts/OFL-Manrope.txt`.

PROJECT has no separate original logo source or Telegram-bot interface screen source in the available files. MV Vape Shop has no confirmed original vector logo. This site uses only existing assets; it does not recreate missing project materials. The MV case intentionally omits packaging and other unconfirmed deliverables.

The previous portfolio remains a separate project and is not required for this site to run.
